방 배정 프로그램
내 구글 계정으로 쓰는 방법

연수생이 폰으로 숙박 여부와 같은 방 희망을 고르면, 프로그램이 규칙에 맞춰 방을 배정해 줍니다. 아래 순서대로 한 번만 설치하면 됩니다.

설치 약 10분프로그램 설치 없음연수생은 계정 불필요

이 프로그램은 이렇게 동작합니다.

  • 관리자(선생님): 내 구글 계정으로 한 번 설치합니다. 명단 올리기, 방 설정, 자동 배정, 결과 공개를 합니다.
  • 연수생: 구글 계정 없이 주소만 열고, 휴대전화 번호로 본인 확인을 한 뒤 선택합니다. 아이폰도 됩니다.
  • 데이터: 명단과 선택 내용은 내 구글 드라이브의 "방배정 데이터" 시트에만 저장됩니다. 다른 설치본과 섞이지 않고, 다른 사람은 볼 수 없습니다.

0준비물

  • 구글 계정 1개 — 개인 계정(@gmail.com)을 권장합니다.
  • 컴퓨터와 인터넷 브라우저 (크롬 권장)
  • 설치 파일 (아래 버튼으로 받기)
학교·기관 계정은 주의
기관 구글 계정은 관리자가 "모든 사용자에게 공개하는 배포"를 막아 두는 경우가 있습니다. 4단계에서 "모든 사용자"가 보이지 않으면 개인 계정으로 해 주세요.
⬇ 설치 파일 받기 (zip)

받은 zip 파일은 압축을 풀어서 쓰세요. (마우스 오른쪽 → 압축 풀기) 안에 파일 5개와 안내문이 들어 있습니다.

appsscript.json
Assign.js
Store.js
Api.js
Index.html
파일 내용 보는 법
파일을 마우스 오른쪽 → 연결 프로그램 → 메모장으로 엽니다. 아래 3단계에서 내용을 Ctrl+A(전체 선택) → Ctrl+C(복사)해서 붙여넣습니다.

1새 프로젝트 만들기

  1. 브라우저에서 script.google.com에 들어갑니다.
  2. 구글에 로그인되어 있는지 확인하고, 왼쪽 위 ＋ 새 프로젝트를 누릅니다.
  3. 왼쪽 위의 "제목 없는 프로젝트"를 눌러 이름을 방배정으로 바꿉니다.

2설정 파일이 보이게 하기

  1. 왼쪽 메뉴에서 ⚙ 프로젝트 설정을 누릅니다.
  2. "'appsscript.json' 매니페스트 파일을 편집기에 표시"를 체크합니다.
  3. 왼쪽 메뉴의 < > 편집기로 돌아옵니다.

3파일 5개 붙여넣기

왼쪽 파일 목록에서 아래 순서대로 합니다.

  1. appsscript.json을 눌러 열고, 안의 내용을 전부 지운 뒤 받은 appsscript.json 내용으로 바꿉니다.
  2. 처음부터 있던 코드.gs는 삭제합니다. (파일 오른쪽 ⋮ → 삭제)
  3. 파일 목록 옆 ＋ → 스크립트를 눌러 이름을 Assign으로 만들고, 받은 Assign.js 내용을 붙여넣습니다.
  4. 같은 방법으로 Store(← Store.js), Api(← Api.js)를 만듭니다.
  5. ＋ → HTML을 눌러 이름을 Index로 만들고, 받은 Index.html 내용을 붙여넣습니다.
  6. Ctrl+S로 저장합니다.
파일 이름 뒤에 .gs가 자동으로 붙는 것은 정상입니다. 이름의 대소문자(Assign, Store, Api, Index)는 그대로 지켜 주세요.

4배포하기

  1. 오른쪽 위 배포 → 새 배포를 누릅니다.
  2. "유형 선택" 옆 톱니바퀴 → 웹 앱을 고릅니다.
  3. 설명: 아무거나 (예: 방배정)
  4. 다음 사용자로 실행: 나
  5. 액세스 권한이 있는 사용자: 모든 사용자
  6. 배포를 누릅니다.
맞게 했는지 확인: 실행 사용자는 "나", 액세스는 "모든 사용자"여야 연수생이 구글 계정 없이 들어올 수 있습니다.

5권한 허용 (처음 한 번)

  1. 액세스 승인 버튼을 누르고 내 구글 계정을 고릅니다.
  2. "Google에서 확인하지 않은 앱" 화면이 나오면 왼쪽 아래 고급 → 방배정(안전하지 않음)으로 이동 → 허용을 누릅니다.
내가 만든 프로그램이 내 드라이브에 시트를 만들기 때문에 나오는 경고입니다. 다른 사람에게 권한을 주는 것이 아닙니다.

6내 주소(배포 ID) 확인하기

배포가 끝나면 웹 앱 URL이 나옵니다. 아래 모양입니다. [복사]를 눌러 두세요.

https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxx(긴 글자)/exec

굵게 표시한 가운데 긴 글자가 "배포 ID"입니다. 아래 칸에 웹 앱 URL을 통째로 붙여넣으면 내 주소가 자동으로 만들어집니다.

관리자 화면에서 새 연수 만들기를 하면 연수생 주소가 자동으로 나타납니다. 그 주소를 복사해서 연수생에게 보내세요.

주소 형식이 맞지 않아요. script.google.com/macros/s/…/exec 모양인지 확인해 주세요.

7관리자 시작하기

  1. 위에서 만든 관리자 주소를 엽니다.
  2. 처음에는 관리자 비밀번호를 정하는 화면이 나옵니다. 잊지 않을 비밀번호를 정해 주세요. 이때 "방배정 데이터" 시트가 내 드라이브에 자동으로 만들어집니다.
  3. 새 연수 만들기 → 연수 이름을 입력하고 만듭니다.
  4. 순서대로 진행합니다. ① 명단 올리기 → ② 객실·옵션 → (연수생 응답 받기) → ④ 자동 배정 → 조정 → 확정·공개
연수생에게 보낼 것은 "연수생 주소" 하나뿐입니다. 관리자 주소는 나만 알고 있으세요.

8연수생은 이렇게 씁니다

  1. 받은 주소를 폰으로 엽니다. (구글 계정 불필요)
  2. 휴대전화 번호를 입력해 본인 확인을 합니다.
  3. 내 이름표를 출근 / 숙박 / 같은 방 요청 칸으로 끌어다 놓아 고릅니다.
  4. 같은 방을 쓰고 싶은 분은 서로 선택해야 확정됩니다.
  5. 관리자가 결과를 공개하면 같은 주소에서 내 방을 확인합니다.

자주 묻는 질문

"모든 사용자" 선택지가 안 보여요

학교·기관 구글 계정은 관리자가 공개 배포를 막아 둔 경우입니다. 개인 구글 계정(@gmail.com)으로 1단계부터 다시 해 주세요.

연수생 화면에 "서버에 연결할 수 없어요"가 떠요

4단계의 액세스 권한이 "모든 사용자"인지 확인하세요. 배포 → 배포 관리에서 볼 수 있습니다. 주소의 배포 ID가 한 글자라도 다르면 연결되지 않으니 6단계의 주소 만들기 칸으로 다시 만들어 보세요.

"확인되지 않은 앱" 경고가 나와요

정상입니다. 5단계처럼 고급 → 이동 → 허용을 누르면 됩니다.

명단은 어디에 저장되나요? 다른 사람이 볼 수 있나요?

내 구글 드라이브의 "방배정 데이터" 시트에만 저장되고, 다른 사람은 볼 수 없습니다. 연수생 전화번호는 해시로만 저장되며 화면에는 끝 4자리만 보입니다.

연수생이 번호를 잘못 입력했거나 폰을 바꿨어요

관리자 화면의 명단에서 해당 연수생의 본인 확인을 해제할 수 있습니다. 해제 후 연수생이 새로 입력하면 됩니다.

프로그램이 업데이트되면 어떻게 하나요?

화면은 공용이라 자동으로 바뀝니다. 서버 코드가 바뀐 경우에만 새 설치 파일을 받아 3단계처럼 붙여넣고, 배포 → 배포 관리 → ✎ 편집 → 버전: 새 버전 → 배포를 하면 됩니다. 주소(배포 ID)는 바뀌지 않습니다.

컴퓨터를 꺼도 되나요?

네. 모든 것이 구글과 인터넷에서 돌아가서 내 컴퓨터와 무관합니다.
